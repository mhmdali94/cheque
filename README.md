# شيكاتي

تطبيق ويب عربي لكتابة الشيكات ومعاينتها وطباعتها بدقة المليمتر على أصل الشيك الفارغ. كل البيانات محلية على جهاز كل محاسب، ومفيش خادم تطبيقات ولا تسجيل دخول.

## التشغيل والبناء

محتاج Node.js إصدار ٢٢ أو أحدث.

```bash
npm install
npm run dev        # تشغيل للتطوير
npm test           # اختبارات الوحدة
npm run lint       # فحص الكود
npx playwright install chromium   # مرة واحدة
npm run test:e2e   # اختبارات المتصفح
npm run build      # البناء النهائي في مجلد dist
```

## النشر على CyberPanel خطوة بخطوة

١. **إنشاء الموقع:** من CyberPanel افتح Websites ثم Create Website، واكتب الدومين.

٢. **تفعيل SSL:** من Websites ثم List Websites ثم Manage، اختار Issue SSL. الشهادة إلزامية، لأن التثبيت كتطبيق والعمل بدون إنترنت مش بيشتغلوا من غير HTTPS.

٣. **البناء على جهازك:**

```bash
npm install && npm run build
```

٤. **الرفع:** افتح File Manager للموقع، وادخل `public_html`، وامسح الملفات الافتراضية، وارفع **محتوى** مجلد `dist` (مش المجلد نفسه).

٥. **التأكد من ملف `.htaccess`:** الملف بيبدأ بنقطة، فبعض البرامج بتخفيه. فعّل إظهار الملفات المخفية واتأكد إنه موجود في `public_html`. لو ما اترفعش، ارفعه من `dist/.htaccess`.

٦. **إعادة تشغيل الخادم:** OpenLiteSpeed بيقرا قواعد `.htaccess` بعد إعادة التحميل. من CyberPanel افتح Server Status ثم LiteSpeed Status واضغط Reboot، أو نفّذ على السيرفر:

```bash
systemctl restart lsws
```

٧. **الفحص:** افتح أي مسار داخلي زي `https://الدومين/drafts` واعمل تحديث للصفحة. لو ظهر التطبيق، التحويل شغال.

```bash
curl -I https://الدومين/sw.js
curl -I https://الدومين/index.html
```

المطلوب `Cache-Control: no-cache` في الاتنين. OpenLiteSpeed ممكن يتجاهل توجيهات الكاش في `.htaccess`، وساعتها من vHost Conf ضيف:

```
context /sw.js {
  location                $VH_ROOT/public_html/sw.js
  allowBrowse             1
  extraHeaders            Cache-Control no-cache, no-store, must-revalidate
}
```

وكرر نفس الجزء لـ `/index.html`. تحديث التطبيق بيشتغل حتى من غير الخطوة دي، لأن المتصفح بيتجاوز كاشه العادي عند فحص `sw.js`.

## إعداد طابعة Toshiba e-STUDIO408P

### طريقة إدخال الشيك

- من **الدرج الأمامي اليدوي**، في منتصف الدرج.
- **بالطول**: الحافة القصيرة تدخل الأول. الإدخال بالعرض بيعمل انحشار برقم ٢٠٢.
- **الوش لفوق**، و**الحافة الشمال (ناحية الشعار)** هي اللي تدخل الأول. الحافة العليا للشيك (ناحية التاريخ) تبقى على يمينك، وشريط الترميز على شمالك.
- **اقفل الموجّهين على الشيك**. لو بعاد عنه الورقة بتميل وتنحشر.

### إعدادات لوحة الطابعة

زر المفتاح، ثم `Paper`، ثم `Tray Configuration`:

| الإعداد | القيمة |
|---|---|
| `Paper Size/Type` ثم `MP Feeder Size` | `A4` |
| `MP Feeder Type` | `Plain Paper` |
| `Configure MP` (لو ظهر) | `First` |
| `Substitute Size` | `All Listed` |
| `Default Source` | `Tray 1` (البديل `MP Feeder`، وساعتها كل طباعة المكتب هتسحب من الأمامي) |

وضع «صفحة بمقاس الشيك» بديل لو وضع A4 عمل انحشار أو رسالة عدم تطابق مقاس. يحتاج `MP Feeder Size` = `Universal`، ومن `Paper` ثم `Media Configuration` ثم `Universal Setup`: الوحدة `Millimeters`، و`Portrait Width` = عرض الشيك، و`Portrait Height` = طول الشيك.

### حل المشاكل

- رسالة `Load Tray 1 with Plain...`: ألغِ المهمة بزر X، واتأكد من `MP Feeder Size`، وابعت تاني.
- انحشار برقم ٢٠٢: افتح الباب الأمامي وطلّع الورقة، واتأكد إن الشيك داخل بالطول.
- على الكمبيوتر: في خصائص الطابعة خلّي `Paper Source` = `Manual Feed` أو `Automatically Select`، مش `Tray 1`.

## المعايرة قبل أول شيك حقيقي

كل الخطوات في شاشة «الطابعة والمعايرة»، وبتتعمل **على كل جهاز هيطبع**، لأن نوافذ الطباعة بتختلف في التصغير التلقائي.

١. **جهّز ورق تجربة:** صوّر الشيك عدة نسخ بالحجم الأصلي ١٠٠٪، وقصّها بنفس أبعاده بالظبط.

٢. **حدد الاتجاه:** اطبع صفحة الاتجاه على ورقة مقصوصة، وامسكها زي ما بتقرا الشيك، واختار الصورة اللي طلعت معاك. اتجاه التدوير الحالي مستنتج من تجربتك على الطابعة، والخطوة دي بتأكده.

٣. **صحح المقياس:** اطبع صفحة المعايرة على A4 عادي، وقِس المسطرتين بالمليمتر، وادخل القياس. لازم يطلعوا ١٠٠ مم بعد التصحيح.

٤. **اضبط القالب:** من «قوالب الشيكات» قِس شيكك وحرّك الحقول فوق صورته. الأماكن الجاهزة تقريبية.

٥. **جرّب على ورقة مقصوصة:** اطبع تجربة، وحط الورقة فوق الشيك الأصلي قدام النور، واستخدم أزرار «الكلام طلع فين؟» لحد ما يتطابق. كل ضغطة نص مليمتر.

٦. **سجّل النجاح:** اضغط «التجربة نجحت». لو الطابعة أو القالب اتغيروا كرر التجربة.

## النسخ الاحتياطي

البيانات على الجهاز بس. اعمل نسخة بانتظام من شاشة «النسخ الاحتياطي»، ويفضل تشفيرها بكلمة سر. لو كلمة السر ضاعت الملف مش هيتفتح أبداً.
